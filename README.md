# Discord 消息清理

Chrome Manifest V3 扩展。通过 Discord 网页的滚动区扫描聊天历史，筛选并预览消息，勾选后可一次确认批量处理。

## 安装或更新

1. 克隆本仓库，或通过 GitHub 的 **Code → Download ZIP** 下载并解压。
2. 在 Chrome 打开 chrome://extensions/，开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 manifest.json 的目录。有旧版时用新版文件替换原目录里的文件，然后在扩展页重新加载。
4. 打开或刷新 Discord 网页版。右侧会自动出现清理图标。点击它展开或收起面板，也可通过 Chrome 工具栏打开。

## 筛选与删除

1. 选择 **当前聊天** 或 **私信和群聊**。点 **扫描聊天历史** 读取当前聊天的历史。点 **扫描所有私信** 会依次打开 Discord 当前列出的私信和群聊。扫描期间可以停止。
2. 在 **发送者** 下拉框中选择「所有发送者」或一个昵称。可选择「手动输入」来填写完整的显示名或用户 ID。同名时，列表会显示可识别的 ID 以便区分。
3. 在 **高级筛选** 里可按关键词、正则表达式、日期和消息类型筛选，并选择从最早或最新开始。日期按浏览器本地时间计算，包含起止两日。
4. 筛选会自动更新，已有选择会清空。勾选候选消息，或用 **全选匹配** 将结果加入队列。
5. 点击 **批量删除**，核对会话和消息数后点击 **确认删除**。扩展会依次处理该次勾选的消息，并显示已删除、跳过和未完成的数量。点 **停止** 或按 Escape 可中止后续操作，已发出的删除动作可能完成。

也可以用 **处理下一条** 打开 Discord 的原生确认框，或用 **快速点选** 直接选择一条消息。

Discord 会在处理时判断删除权限。服务器中，删除他人消息需要 **管理消息** 权限。没有删除选项的消息会跳过。遇到无法核对的确认框或无法观察到删除结果时，批量处理会暂停，其余消息留在队列中。

扩展通过 Discord 网页的滚动区读取历史，不调用账户 API。面板会提示是否读到聊天开头。若 Discord 暂停加载或当前滚动区无法识别，可再次扫描，或手动滚动后点 **刷新已加载**。处理队列中已移出视口的消息时，扩展会尝试在历史中定位该条消息。

扩展仅在 Discord 网页中运行。筛选与队列保存在当前标签页的内存中，收起面板后仍可继续使用。刷新或关闭标签页会清空这些数据。
