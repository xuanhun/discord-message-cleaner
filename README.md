# Discord 消息清理

Chrome Manifest V3 扩展。筛选 Discord 网页版中已加载的消息，预览、勾选后逐条打开 Discord 的原生删除确认框。

## 安装或更新

1. 克隆本仓库，或通过 GitHub 的 **Code → Download ZIP** 下载并解压。
2. 在 Chrome 打开 chrome://extensions/，开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 manifest.json 的目录。有旧版时用新版文件替换原目录里的文件，然后在扩展页重新加载。
4. 打开或刷新 Discord 网页，在 Chrome 工具栏点击 **Discord 消息清理**。

## 筛选与删除

1. 选择 **当前聊天** 或 **私信和群聊**。扫描会依次打开 Discord 当前列出的私信和群聊。也可以打开单个私信，点 **加入当前私信**。
2. 留空发送者以匹配所有人，或选择、输入准确的显示名或可识别的用户 ID。同名时使用用户 ID 区分。部分消息的作者资料可能没有加载。
3. 在 **高级筛选** 里可按关键词、正则表达式、日期和消息类型筛选，并选择从最早或最新开始。日期按浏览器本地时间计算，包含起止两日。
4. 点击 **应用筛选**。勾选候选消息，或用 **全选匹配** 将结果加入队列。
5. 点击 **处理下一条**。核对 Discord 原生确认框后，手动点击 **删除** 或 **取消**。用 **跳过本条** 可将消息移出队列，用 **快速点选** 可直接选择一条消息。

Discord 会在处理时判断删除权限。服务器中，删除他人消息需要 **管理消息** 权限。没有删除选项的消息会跳过。

预览以 Discord 当前加载到网页中的内容为准。可滚动聊天以加载更多历史，再点击 **读取当前聊天** 或 **加入当前私信**。已加入队列的旧消息如果暂时不在页面中，可在 Discord 找到该消息后重试。

扩展使用 activeTab 和 scripting 权限。筛选与队列仅保存在当前页面内存，刷新或关闭面板会清空队列。
