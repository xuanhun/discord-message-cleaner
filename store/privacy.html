Discord Message Cleaner Privacy Policy

Effective November 20, 2026.

Discord Message Cleaner reads the messages displayed in Discord when you open the cleanup panel, refresh the loaded messages, or scan chat history. This includes message text, sender names and IDs, timestamps, chat and message IDs, and whether a message contains media or attachments. The extension uses these data to filter and preview messages and locate the items you choose to delete.

The extension processes these data in memory in the current Discord tab. A page refresh or tab closure discards the data held by the extension. Chat contents and account credentials are not transmitted by the extension or shared with the developer, analytics providers, or other third parties. When you confirm a delete action, Discord's own webpage processes the deletion under your signed-in account. Discord's own processing is governed by its privacy policy.

The extension uses its Discord site access to provide the floating button and cleanup workflow. Its use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Developer contact and project links are available through the publisher's GitHub profile.

Discord 消息清理隐私政策

生效日期为 2026 年 11 月 20 日。

当你打开清理面板、刷新已加载消息或扫描历史时，扩展读取 Discord 网页中显示的聊天数据，包括消息正文、发送者名称和 ID、时间戳、会话和消息 ID，以及消息是否含媒体或附件。扩展将这些信息用于筛选、预览和定位你选择删除的消息。

这些信息只在当前 Discord 标签页的内存中处理。刷新网页或关闭标签页会清除扩展持有的数据。扩展不会传输聊天正文或账号凭据，也不会向开发者、分析服务或其他第三方分享这些信息。当你确认删除时，Discord 网页会以当前登录账号执行删除，Discord 自己的数据处理适用其隐私政策。

扩展使用 Discord 站点访问权限提供悬浮按钮和清理功能。扩展对用户数据的使用遵守 Chrome 网上应用店的用户数据政策，包括有限使用要求。

开发者的联系和项目入口见发布者的 GitHub 主页。
